# Kundali Screen

A **Kundali Screen** built in React Native for rendering astrological charts with responsive layouts and animated backgrounds. The screen includes a Kundali chart, animated circles, and displays values such as house numbers dynamically, ensuring a smooth user experience across devices.

## Table of Contents
- [Features](#features)
- [Installation](#installation)

## Features

- **Astrological Chart Layout**: Displays a Kundali chart with house numbers and values.
- **Animated Background**: Uses `react-native-reanimated` for smooth, visually appealing background animations.
- **Responsive Design**: Optimized for various screen sizes, ensuring a consistent experience on different devices.
- **SVG Integration**: Leverages SVGs for precise and scalable graphics within the Kundali chart.

## Installation

1. Clone the repository:

   git clone https://github.com/yourusername/kundali-app.git
   cd kundali-app

2. Install dependencies:

   npm install

3. Run android

   - Open Android Studio and select your emulator or connect a physical device.
   - In the terminal, navigate to the project folder and run:
     npm start
     npx react-native run-android
     
   - This will start the Android app on your emulator or device.
